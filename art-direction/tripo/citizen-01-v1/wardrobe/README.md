# CIVRUM 01 号城市居民 · 夹克与内搭

01 号沿用[角色设定图](../01-front.png)的青绿色敞襟夹克、黄色袖带和米色连帽衫。夹克衣身、袖子和袋口取自用户提供的 Tripo 原模，门襟折边、领口和袖口做了收边。内搭保留帽兜和抽绳，补齐衣身、长袖、袖口和下摆。头部沿用[头发拆分工程](../hair-study/README.md)。

| 文件 | 使用方式 |
| --- | --- |
| [Blender 工程](CIVRUM_01_Wardrobe.blend) | 在大纲中切换 `Citizen01_Jacket` 的眼睛。选中夹克按 H 临时隐藏，Alt+H 恢复视图中隐藏的对象。 |
| [完整人物 GLB](CIVRUM_01_Wardrobe.glb) | 按节点名控制夹克 `Citizen01_Jacket`、内搭 `Citizen01_Hoodie` 和头发 `Citizen01_Hair` 的可见性。 |
| [独立夹克 GLB](CIVRUM_01_Jacket.glb) | 单件网格使用完整人物的原点、单位及 A 字姿势。 |
| [三视角穿脱对照](CIVRUM_01_Jacket_Check.png) | 上排显示夹克，下排隐藏夹克。 |

Blender 5.3 已重新打开工程，并重新导入两份 GLB。完整人物有 13 个网格、12,202 个三角面，其中夹克 2,086 面，内搭 3,499 面。独立夹克的三角形和位置与完整人物中的夹克一致。

当前验证覆盖静态 A 字姿势。以 45 度间隔检查八个水平视角，在外套原有覆盖区域的内部采样，新补内搭超出夹克表面 0.00035 个源模型单位的采样点为零。绑定骨骼后仍需测试抬臂、弯肘时的肩袖变形。衣物使用纯色材质。
