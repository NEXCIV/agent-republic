# ADR-006：共享城市生活 — 受限移动试点

- 日期：2026-11-27
- 范围：E3-05，生活模拟阶段 0 及阶段 1 的首个可验证切片
- 状态：本轮隔离试验的开发约束；不代表其已实现、已通过验收或获准对公网开放

## 背景与取舍

现有本机咖啡街、桌面游客试玩均按浏览器会话隔离。其移动、任务和记录可重放，但两个浏览器不属于同一个城市。把游客存档直接改成同一份，会让不同访客能操纵同一个角色，不能证明居民归属、动作授权或共享活动的一致性。

先在独立试验环境建立一个共享的链下生活**动作与回执服务**，只验证两名已分配测试居民的固定点位移动。保留现有游客试玩和本机 MCP，不使用其 cookie 或数据库记录作为共享居民的所有权证明。

这不是第二套正式世界引擎。本轮仅记录隔离的生活活动；`packages/domain/src/world-v1.ts` 仍是唯一 `WorldFrameV1`、`AgentObservationV1` 定义。正式场景 `district-01@1`、60 秒模拟 tick、事件来源、合约参数及 `WorldFrameV1.facts` 均不修改。活动日志中的命令时刻和路线只是 DEMO 行为证据，不是链上事实。试点复用 300 米预览场景的已测绘步道路网，只开放 `cafe`、`plaza`、`governance`、`works` 四个固定地点，而非任意坐标。未来接入正式世界前，另立场景及投影 ADR，若需要版本/schema 演进，则同步规格与测试向量。不得将测试居民写入正式公民列表、增加任何真实公民人数或令链上项目阶段发生变化。

## A. 账号、居民和授权边界

1. 正式账号沿用已有站内 `app_user`、认证会话及既有的 owner 绑定机制，不新建平行的登录/链上身份体系。首轮共享生活预设邀请制、一账号一链下居民；认领本身不产生正式公民权利，不等价于 `CitizenRegistered`。实际生产登录方式、认领流程和首次开放条件须在接入实现前经确认及实测，目前尚未确定。
2. 隔离试点只预分配 `01` 和 `02` 两名测试居民，由内部操作者为单一居民发放、轮换、撤销不透明的限时应用凭据；持久层保存凭据哈希，不保存其明文。试验凭据默认有效 1 小时，最长 24 小时，仅适用于内部测试，未来正式授权期限需独立评审。操作服务从有效凭据查得可信测试主体，固定授权范围仅为 `observe`（观察同城可见的移动状态）、`moveTo`（移动该居民）和 `receipt`（读取该居民自己的回执）；不开放凭据发放、轮换和撤销给 Agent。调用参数、钱包地址字符串、浏览器游客 ID、模型自述均不能改变该主体，不能冒领其他居民。测试凭据不是生产用户登录凭据，不得在正式路由直接接受。
3. 后续 HTTP 和 MCP 的授权适配层必须从有效的凭据及持久归属记录确定主体；按独立作用域限制观察、提交动作和读取自己的回执。发放、暂停、撤销、过期及被移除的归属要成为明确的服务端状态；本轮内部操作者的凭据接口不替代正式用户授权流程。应用连接凭据不等于 Agentic Wallet、签名授权或链上 Delegate；客户端持有的模型供应商密钥始终由自身 Harness 管理。
4. 在正式开放前，验证同一动作经 HTTP/MCP 得到一致的权限校验、语义及回执。在未完成目标 Harness 的真实协议和授权验收前，不开放远程 MCP 或浏览器共享认领。本轮不建立匿名共享写接口，不接管钱包，不部署到公网。

## B. 最小动作契约与权威执行

`moveTo` 动作使用严格输入 `{ action: 'moveTo', requestId: uuidV4, destination: { place } }`，`place` 仅允许四个固定地点的 ID，幂等 UUID 统一转为小写。服务端根据凭据确定居民 ID，从自身状态确定出发点、路线、速度及到达时刻；不得从请求接受任意坐标、被操作的居民 ID、时钟、到达证明、链上写入、自由文本或未经审核的公共事件。

一期只支持前往固定点位。新测试存档内 `01` 从中央广场 `plaza` 出发、`02` 从咖啡摊 `cafe` 出发，使用同一个服务端路线版本及 4 米/秒的演示移动速度。服务端入参校验、权限、位置/忙碌状态检查、动作受理及唯一回执属于同一应用服务；HTTP、MCP、客户端动画将只做适配与呈现。隔离试点采用专用 SQLite 存储居民、凭据和动作记录，复用支持 `node:sqlite` 的运行条件，不读取或复用浏览器游客/本机试玩数据库。在动作受理和凭据生命周期操作中保持原子边界；未来生产存储另行迁移和验证。

| 项目 | 规则 |
| --- | --- |
| 动作受理 | 有效居民在当前可行动状态下可前往白名单位置；未知点位、错误主体、超出固定授权范围、无效/过期/已撤销授权，以及已有未完成移动都不能产生新动作 |
| 幂等键 | 以居民与请求 ID 划定范围；完全相同的动作重放返回同一行动回执的当前状态，不重复移动；同一居民的相同请求 ID 若内容不同则冲突；不同居民的请求命名空间互不占用 |
| 回执 | 明确区分受理与完成：受理不等于到达，完成依据服务端已记录的开始和到期时刻；错误原因可机器识别，但不披露其他居民的私有数据 |
| 时间 | 注入或由服务端读取可信时间；移动耗时按路线长度和演示速度计算并向上取整到毫秒，对同一已受理的记录，按同样的时间输入能重现移动状态。到期前未到达，到期时/之后由下一次获授权的事务补算到达，记录原定到达时刻；重复观察不得重复生成完成事实 |
| 同时活动 | 第一版每个居民仅有一个尚未完成的移动，不锁住其他居民；两名居民可在同一共享试点独立选择路线，随后同时出现在相同目的地 |
| 公开/私有 | 试点共同可见的信息只包含测试居民 ID、位置、可观察的路线及其服务端时间/事件来源，标注 `AI SIMULATED · DEMO`。共享投影至多返回最近 40 条移动开始/到达事件，只向已授权试点主体可见；主体归属、访问凭据、请求与私有回执细节不得进入共同投影或其他居民的私有读取结果 |

隔离试验设置每位测试居民最多 300 条已受理移动动作记录的容量限制，重放已有动作仍按幂等规则读取现有回执；此上限是资源和试验的边界，不是生产可承载人数、吞吐量或反机器人能力的保证。

不能用“AI 说它到了”、客户端动画播放到结尾、浏览器按键或钱包状态代替动作结果。已受理动作的时间推进不需要触发模型调用。凭据撤销或轮换不撤销已受理的确定性移动；移动可以按既有记录结束，不能静默改写历史。用户级暂停流程在正式授权阶段实施。

## C. 分阶段交付与验收清单

当前切片只建立领域契约、凭据受限的隔离共享移动服务与可复现测试。无需先开放真实账号认领，亦无需为了测试引入公网接口或新场景资产。以下为验收目标，实际运行结果另行记录：

| 用例 | 通过条件 |
| --- | --- |
| 同城可见 | 测试居民 A 发起移动；测试居民 B 仍有独立动作权，但从共同读取结果可观察到 A 在前往固定地点及到达后的状态；B 的位置和记录不会被 A 改写 |
| 正确归属 | 不可信调用参数不能指定或操纵另一个居民；读取自己回执时必须匹配授权主体；共同可见结果不含私有凭据或私人请求数据 |
| 可重试 | 重试相同请求返回原回执；同 ID 改目的地被拒绝；两名居民可独立使用同名幂等 ID；重复动作和到期重算无重复结果 |
| 规则限制 | 错误动作、未知地点、超出固定授权范围或越权、无效/过期/轮换/撤销凭据、移动中重复新动作被明确拒绝，不产生新的移动记录 |
| 时间边界 | 注入可控制时钟验证受理后立即、到期之前、恰好到期、之后和重复观察；路线起终点与可见状态一致 |
| 持久恢复 | 关闭测试数据库连接并重新打开，核对已保存行程、动作回执、时间推进及凭据有效状态；整个测试使用独立数据库 |
| 隔离 | 无链上/钱包写入、无模型调用、不影响本机咖啡街存档或独立游客；不创建并行的正式 WorldFrame，不新增主网数据或冒充链上确认 |

在仓库根目录、现有锁定依赖已安装且 Node.js 22.13+ 支持 `node:sqlite` 的环境中，运行下列专项测试。不需要启动 Web 服务、连接真钱包、使用模型密钥或打开现有游客/本机试玩存档。

```powershell
node node_modules/vitest/vitest.mjs run packages/domain/test/shared-city-pilot.test.ts apps/web/test/shared-pilot-store.test.ts
```

这是复现验收的命令；测试是否通过及跳过项应按实际工具输出报告，不能用本文代替测试结果。

下一切片才接入真实站内会话、持久化真实账号与居民归属、用户确认的凭据发放/暂停/撤销及对外的受权适配层，正式数据方案遵循 PostgreSQL 事务、唯一约束和 Redis/BullMQ 到期处理。届时必须补测独立工作进程重启、并发请求、持久化恢复和暂停/撤销竞争。隔离 SQLite 测试通过也不等于 PostgreSQL、多进程或网络部署验收通过。正式远程 MCP 按实际 Harness 的协议与认证要求单独验收，不能把本机 stdio 或无鉴权 HTTP 当成远程接入已完成。

## D. 保持不变与不纳入本轮

- 合约、Agent ID 资格、owner 权利、BUILD/REP、正式投票贡献以及 Gate A 均以原规格和实际链证据为准。
- `WorldReducer` 保持纯函数；正式 `WorldFrameV1` 仍只包含已确认链事实、审核后的公开信息和确定性模拟，私有回执/凭据不进入公开 Frame。
- 共享会面、自由文本发言、内容审核、关系、早报和纸条在后续城市生活任务中逐步交付，暂不以模拟记录冒充这些能力。
- 本机 `/api/nexciv-preview/cafe`、独立 HTTPS `/api/nexciv-preview/guest`、现有页面和原始 3D 资产不因本切片被替换。
