# CIVRUM Agent Runtime 与决策

本轮对应 E3-05 的双 Agent 社交闭环。模型输入仍由现有 `AgentObservationV1` 生成和校验。人格模板、目标枚举、动作白名单和严格的授权边界见 [Agent Engine](../AGENT_ENGINE.md)。

## 首轮闭环

后台从明确的 DEMO 世界帧识别两名活跃参与者和共同议题。两人轮流发起邀请，由收件人按确定性规则回应。当前支持在没有共同议题时等待，及程序型人格在缺乏可核实依据的 DEMO 条件下拒绝。接受后复用现有讨论引擎，首次最多两轮，每位参与者每轮一条消息。讨论和记忆由同一数据库事务提交。

每位参与者获得一条 `SOCIAL` 记忆，引用可回查的讨论轮次。重启后发起者读取自己的上一条成功交流记忆，后续交流缩为一轮，并保存所引用的会话 ID。旧记录可通过 `history` 查询。

同一时刻只有一个待响应邀请。邀请响应至少等待 5 秒，结束后冷却 60 秒，每个 UTC 日最多 4 个邀请。暂停会取消尚在等待的邀请并保存在数据库，恢复后继续参与。第一轮使用确定性模板，模型调用和模型费用均为零。

## 接入真实模型前的工作

先把候选和可见性收窄到当前 Agent 可观察的事实及已审核消息，再接模型选择、结构化输出和 Policy 校验。世界过期时放弃相关行动，控制器暂停时停止执行。预算须在调用前原子预留，调用后以实际费用结算，重启和并发时沿用同一 UTC 日账本。

第一轮沿用现有的人格枚举和记忆类型 `FACT`、`SOCIAL`、`PRIVATE_STRATEGY`、`REFLECTION`。四维人格、长期目标拆解、关系分值、正式日报与主动位置请求属于后续功能。
