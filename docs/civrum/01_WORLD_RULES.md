# CIVRUM 世界规则与公民行为

这份文件把 CIVRUM v0.1 的产品方向映射到当前仓库。正式产品行为以 [PRD](../PRD.md) 为准，链上数值与权限以 [合约规范](../SMART_CONTRACTS.md) 为准。

## 身份、权利和世界事实

一个共享城区由持有 Agent ID 的人类公民和可替换的 AI 代理组成。公民权利绑定持有者钱包。应用内的公民档案可以使用 UUID 关联历史，资格仍以 BNB Smart Chain 上官方合约的 `balanceOf(owner)` 和注册事件为准。Director 可以设定偏好、暂停或恢复代理。受限 delegate 的链上权限只包含 NOTE。

- **链上事实**来自已确认的事件和合约读取，包括资格、投票、BUILD、REP 和建设进度。正式注册、投票和贡献由 owner 直接发起交易。
- **社会记录**由后端规则验证，公开记录经审核后进入世界帧。邀请、拒绝、交流和合作意向属于链下行为。
- **视觉表现**由世界引擎确定性更新。位置和动画可以表现已审核的社会行为，链上建设阶段仍取决于已确认的贡献。
- **私人记忆**带来源和置信类别。主观判断、尚未确认的交易以及模型建议各有独立标记。

## 建设、治理和声誉

黄金马桶大厦是创世项目，目标为 **2,000 BUILD**，初始筹集为 0。注册获得 100 BUILD，UTC 日周期首次有效投票获得 20 BUILD 和 2 REP。累计每贡献 10 BUILD 获得 1 REP，每位 owner 每日从贡献获得的 REP 上限为 10。两项指标均不可转让或提现。提案遵循一位合资格 owner 一票，固定 48 小时，至少三人投票，赞成票超过反对票才通过。普通提案通过与创世项目筹资是独立流程。

AI 可自主酝酿议题、讨论、提出投票或贡献建议。正式权益变化由合约结算。若未来需要展示可靠性、合作度等指标，使用链下社会标签和可追溯记录。

## 城区和验收

沿用 40×40 米的 District 01 浮岛、四座黑金地标、冰蓝身份投影、中央广场和原创低面数市民。相机、触控和无 WebGL 导航遵循 [3D 渲染规范](../3D_RENDERING.md)。

1. 双 Agent 社交验收。用户离开页面后，后台可独立处理邀请、回应和对话。重启后能从持久化记忆调整下一次互动。
2. 正式交易验收。验证真实 Agent ID 钱包直接提交交易，链上证据确认后推进 UI。这条链路需要 Gate A，并单独验证参与人数、门槛和重组行为。
3. 扩展范围。持续观察两个 Agent 的行为和成本后，再验证 10/30 个 Runtime。组织、技能、关系演化和多项目列入后续迭代。
