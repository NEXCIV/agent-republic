# World asset licenses

The council, identity tower, project, original core, environment and citizen in
`world/district-01/v1/` are original procedural assets by the AGENT REPUBLIC
team. Their sources are in `tools/blender/`.

NEXCIV supplied the Tripo-generated Agent Center v3 master for the three
`agent-center-*.glb` editions. The CIVRUM nameplate was made for this project.
The per-file manifest identifies the source and SHA-256 of each edition.
No separate public reuse license was supplied for this model or its textures.
