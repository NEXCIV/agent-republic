# Agent Republic 建模方向

项目优先级是做出完整、好看、能在网页里浏览和交互的城区。交接文档记录历史进度，文中的美术决定可以重新判断。以用户提供的浮岛城区参考图为视觉目标，以 `/world` 默认镜头下的实际画面验收整体效果。

- 整景围绕入口桥、中央广场和后方高台议会组织视线。近景能看见市民和铺地，中景能读出通路，远景的四座地标有各自清晰的轮廓。
- 采用明亮日景、草地岩壁、瀑布、黑金建筑、冰蓝身份投影和暖金灯光。保留参考图里身份塔、议会穹顶、Agent 核心玻璃网壳和黄金马桶纪念雕塑的辨识度。
- 角色以有头发、面部和统一服装的原创 Q 版市民为造型方向，在默认镜头距离下检查身高、行走和可读性。
- 模型交付时在网页里核对材质、比例、地标点击、市民寻路和项目施工阶段。地形抬升或建筑移位涉及入口、导航、交互或版本兼容时，先与用户确认取舍。
- 参考图里的余额、名称和百分比属于画面示意。实际页面按项目规则和真实状态显示。
